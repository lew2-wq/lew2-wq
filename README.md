# Le Wang — Agent Workflows Demo

This branch contains a small, self-contained website showing two examples of how I use AI agents:

- **LinkedIn / browser workflow:** a prompt-based walkthrough showing how a clear instruction plus Codex Browser Use can support browser tasks with human approval checkpoints.
- **User Research workflow:** a case study supported by real workflow screenshots.

## View locally

1. Download this branch as a ZIP.
2. Extract the folder.
3. Open `index.html` in Chrome or another modern browser.

No build step or installation is required.

> The LinkedIn example is a demonstration. No new LinkedIn search or message was performed while creating the site.
